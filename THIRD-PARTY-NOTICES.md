## 1. Core Distribution Software

The official Otter 1.0 distribution (`otter-<version>.zip`, for Windows, Linux and macOS) contains **no redistributed third-party binaries, libraries, packages, or asset files**.

All core execution components, including:
- The Otter interpreter and runtime environment
- The frontend lexer, parser, and AST contracts
- The standard library functions

## 2. Web Target Typography (Runtime CDN)

When compiling Otter programs to web applications using `otter web`, the generated HTML documents include references to Google Fonts CDN for typography. These fonts are loaded dynamically by the web browser at runtime and are not physically redistributed within the Otter distribution payload.

The fonts referenced are:
